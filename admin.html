إزاي أجيب الـ Token من GitHub؟
  1. ادخل GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: اختار Only select repositories واختار ريبو الموقع بس.
  3. Permissions ← Repository permissions ← Contents ← Read and write.
  4. حدد مدة الصلاحية، اضغط Generate token وانسخه (بيظهر مرة واحدة).

الـ Token زي الباسورد بالظبط: متبعتوش لحد ومتحطوش في أي ملف.

الباسورد بيشفّر الـ Token على جهازك بس. الحماية الفعلية من GitHub: من غير الـ Token محدش يقدر يرفع أو يعدّل حاجة.
