# اتحاد طلاب قسم التحكم الصناعي

موقع ثابت (Static) بدون سيرفر ولا قاعدة بيانات، مجاني بالكامل.

## هيكل المشروع
```
ic-union/
├── index.html        الصفحة الرئيسية (كروت المواد)
├── subject.html      صفحة المادة (محاضرات / سكاشن / ملخصات / امتحانات)
├── css/style.css    التصميم
├── img/             اللوجو والأيقونة
├── js/i18n.js       الترجمة (عربي/English) - عدّل النصوص هنا
├── js/theme.js      الوضع الليلي
├── js/settings.js   ربط زراير اللغة والوضع الليلي
├── js/data.js        بيانات المواد (الاسم/الدكتور/اللون). الملفات نفسها في data/content.json
├── js/home.js        منطق الصفحة الرئيسية والبحث
├── js/subject.js     منطق صفحة المادة والتابات ومعرض الصور
└── files/<المادة>/   ارفع هنا ملفات PDF والصور
```

## إضافة ملف جديد
1. حط الملف في `files/<المادة>/` (مثال: `files/physics/lec1.pdf`).
2. افتح `js/data.js` وأضف سطر داخل `content` الخاص بالمادة:
```js
{ cat: "lecture", title: "المحاضرة 1", type: "pdf", url: "files/physics/lec1.pdf", date: "2026-11-10" },
{ cat: "section", title: "سكشن 2", type: "image", url: "files/physics/sec2-1.jpg", date: "2026-11-12" },
```
`cat` = lecture / section / summary / exam — و `type` = pdf / image.
أي ملف عمره أقل من 7 أيام بيظهر عليه "جديد" تلقائياً.

## النشر المجاني (GitHub Pages)
1. اعمل حساب على github.com وأنشئ Repository جديد.
2. ارفع كل محتويات الفولدر.
3. Settings ← Pages ← Branch: main ← Save.
4. هيظهر لك رابط الموقع جاهز لمشاركته على الجروبات.
بدائل مجانية: Cloudflare Pages أو Netlify (اسحب الفولدر وخلاص).

> ملاحظة: مفيش حد أقصى صارم لحجم الملفات الصغيرة، لكن لو الملفات كتير وكبيرة استخدم روابط Google Drive في `url`.
> لازم تشغّل الموقع على سيرفر (مش فتح الملف مباشرة) علشان ES Modules، محلياً: `npx serve` أو إضافة Live Server في VS Code.

## الترجمة والوضع الليلي
- نصوص الواجهة في `js/i18n.js`، وأسماء الدكاترة والمواد بالإنجليزي في `js/data.js` (حقول `teacherEn` و`titleEn`).
- لأي ملف تضيفه ممكن تحط `titleEn: "Lecture 1"` علشان يتترجم، ولو مش موجود بيظهر العنوان العربي.
- اختيار المستخدم (اللغة/الوضع الليلي) بيتحفظ في المتصفح.

## فيديوهات الشرح (YouTube)
ضيف سطر في `content` للمادة بالشكل ده (الصق رابط الفيديو أو الـ Playlist كما هو):
```js
{ cat: "video", title: "شرح المحاضرة 1", titleEn: "Lecture 1 Explained", type: "video", url: "https://www.youtube.com/watch?v=XXXXXXXXXXX", date: "2026-11-10" },
```
الفيديو بيظهر جوه الموقع بـ iframe (بيتحمّل لما الطالب يضغط تشغيل علشان الصفحة تفضل خفيفة). بيدعم روابط `watch?v=` و`youtu.be` و`shorts` و`playlist?list=`.

## ترتيب الملفات
الملفات بتظهر بنفس ترتيب السطور في `js/data.js`، فحط الأحدث فوق لو عايزه يظهر الأول.

## لوحة التحكم (admin.html)
- افتحها من `https://اسم-حسابك.github.io/ic-union/admin.html` (مش متحطة كلينك في أي مكان في الموقع، وفيها noindex فمش بتظهر في جوجل). ممكن تغيّر اسم الملف لاسم صعب التخمين.
- أول مرة: تدخل اسم حسابك والريبو والـ Token، وتختار باسورد للوحة. الـ Token بيتشفّر على جهازك (AES-GCM) ومبيتخزنش كنص عادي.
- بعد كده بتدخل بالباسورد بس. بتتقفل لوحدها بعد 15 دقيقة من عدم النشاط.
- من اللوحة: رفع PDF وصور (أكتر من ملف مرة واحدة)، وإضافة فيديو يوتيوب، وتعديل العناوين، وترتيب العناصر، والحذف.
- كل عملية بتتحفظ كـ commit على الريبو، والموقع بيتحدث بعد 1-2 دقيقة.

### الأمان (مهم)
- الحماية الفعلية من GitHub: من غير الـ Token محدش يقدر يرفع أو يعدّل أو يمسح حاجة، حتى لو فتح صفحة اللوحة. الباسورد بيحمي الـ Token على جهازك بس.
- لما تعمل الـ Token اختاره **Fine-grained** ومحدد على ريبو الموقع بس، بصلاحية **Contents: Read and write** فقط.
- متحطش أي باسورد أو Token داخل ملفات الكود أبداً (أي حد يقدر يقراها).
- لو الـ Token اتسرب أو ضاع الجهاز: امسحه فوراً من GitHub ← Settings ← Developer settings.
- الريبو بيكون Public علشان GitHub Pages المجاني، فأي حد يقدر يشوف الملفات، بس مفيش حد يقدر يعدّل.
